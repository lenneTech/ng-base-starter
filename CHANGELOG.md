# Changelog

All notable changes to this project are documented in this file. The 14.x line (Angular 14, `@nguniversal`, Bootstrap) ends
with version 14.34.0 at commit `7b85967` (last tag `v14.0.1`); its history stays in Git.

### [22.0.3](https://github.com/lenneTech/ng-base-starter/compare/v22.0.2...v22.0.3) (2026-11-07)

### Highlights for adopters

- **A quiet app log behind the reverse proxy.** Behind Traefik (TurboOps) and Caddy (`lt dev`) every request carries `X-Forwarded-*` headers, which SSR used to drop with a two-line warning each: ten lines per request in the app log and in the `lt dev` terminal. SSR now trusts `X-Forwarded-Host` and `X-Forwarded-Proto`, so it sees the public `https://` URL, and the other forwarded headers are removed before rendering. `NG_TRUST_PROXY_HEADERS` (comma separated, Angular's own variable) replaces the trusted list.
- **A forwarded host must be an allowed host.** Angular checks `X-Forwarded-Host` against the same allowed hosts as `Host` (the host of `NG_PUBLIC_SITE_URL`, `NG_ALLOWED_HOSTS`, the local names in `angular.json`) and answers 400 to any other. TurboOps and `lt dev` set it to the public host and need nothing. A proxy that rewrites `Host` to an internal name sets `NG_TRUST_PROXY_HEADERS=x-forwarded-proto`, so `Host` stays the only host SSR sees.
- **No late analytics start after the app is gone.** The lazily loaded Plausible tracker no longer starts once the app was destroyed while it loaded, which ended in an `ObjectUnsubscribedError`; its spec no longer fails under the load of `pnpm run check`.

### [22.0.2](https://github.com/lenneTech/ng-base-starter/compare/v22.0.1...v22.0.2) (2026-11-07)

### Highlights for adopters

### [22.0.1](https://github.com/lenneTech/ng-base-starter/compare/v22.0.0...v22.0.1) (2026-11-06)

### Highlights for adopters

- **`@lenne.tech/ng-base` 22.0.1.** JWT mode keeps `authMode` after sign-in, dialogs scroll again (their styles were dropped by a broken Tailwind source list), and the passkey and 2FA texts are fixed.
- **Disabled AI prompts stay manageable.** The prompt management page lists disabled prompts with their "inaktiv" badge (nest-server 12.7.0 `GET /ai/prompts?includeDisabled=true`; 12.6.x ignores the option), the chat's prompt picker offers enabled prompts only.
- **The built server listens on 3001 by default**, the app port of the backend contract, so `node .output/server/index.mjs` no longer collides with the API on 3000. The Docker image keeps setting `PORT=3000`.
- **Projects generated by `lt fullstack init` pass `check` out of the box**, in npm and vendor mode: unit tests on jsdom as in a fresh lockfile, vendored `src/core/` kept out of the Tailwind scan (the stylesheet had doubled), and contract tests that tolerate what the CLI writes (no `.github/`, the URL block of `lt dev`, the vendor notice, the rewritten `site.ts`).
- **`SITE_REPO_URL` in `src/app/shared/site.ts`** is the only place that names the repository; `null` hides every GitHub link.

## [22.0.0](https://github.com/lenneTech/ng-base-starter/compare/v14.0.1...v22.0.0) (2026-11-06)

### Highlights for adopters

- **Rebuilt from scratch on Angular 22.** The 14.x starter (Angular 14, `@nguniversal`, Bootstrap) is replaced by a fresh `ng new` 22.2.6 app on the lenne.Tech stack: standalone and zoneless with signals, SSR with `@angular/ssr`, Tailwind 4, `@lenne.tech/ng-base` 22.0.0, Signal Forms with Valibot and a generated hey-api client. Routes, pages and UX follow nuxt-base-starter 2.38: sign-in with 2FA and passkeys in cookie and JWT mode, security settings, AI chat and AI administration, a system page, and the bug.lt reporter outside production. Every runtime value comes from `NG_*` environment variables the SSR server reads per request, so one image runs on every stage. It is the frontend `lt fullstack init --frontend angular` puts into `projects/app`. Nothing of 14.x carries over: follow the [14.x to 22.0.0 migration guide](https://github.com/lenneTech/ng-base-starter/blob/v22.0.0/migration-guides/14.x-to-22.0.0.md).
